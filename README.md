# 红策略研究所

《苍翼：混沌效应》多红策略组合教程、策略查询与离线存档数据体工具。

## 使用

下载仓库中的 `index.html`，用现代浏览器直接打开，无需安装依赖或启动服务器。

- 查看原表整理的 76 套 5～9 红组合、五位置路线、传承准备和激活条件。
- 导入存档，添加一个或两个传承用或完整搭配的数据体。
- 选择全潜能，自定义目标策略与品质，自动补齐前置并校验形成顺序。
- 为每个数据体设置 HP、MP 基础上限，选择最多两位来源角色和对应一级传承技。
- 保存个人搭配，导入、导出 JSON；下载原始备份及修改后的存档。

存档在浏览器内存中处理，页面不上传游戏存档。个人搭配保存在当前浏览器，建议另行导出 JSON 备份。

## 修改存档

1. 完全退出游戏，并等待云同步完成。
2. 在「存档与数据体」选择 Save 文件夹内对应的数字存档文件。
3. 配置角色、属性、传承技和策略；完整搭配须先补齐前置并通过校验。
4. 下载原始备份，再下载修改后的存档。
5. 将修改后的文件复制回原位置，改回原来的数字文件名并替换对应槽位。

Windows / Steam 默认目录：

```text
%USERPROFILE%\AppData\LocalLow\91Act\BlazBlueEntropyEffect\Steam\账号ID\Save
```

HP、MP 设置修改基础上限；全潜能和来源角色不会自动提高这两项基础值。所选传承技以一级保存，并附带来源角色默认天赋和初始攻击力。两位来源角色须彼此不同，也不能与载体角色相同。形成路线中的传入策略与两项传出策略分别计算。

## 格式与验证范围

目录与存档结构参考 Steam Windows App ID 2273430、Build ID 25627491。游戏更新可能改变目录和格式。纪念方案及涉及契约、黑市的路线须留意版本与特殊条件，计算超时不代表方案无解。

已用合成存档校验编解码、容量、编号、原有数据保留、单个/批量添加与错误拒绝；代表性的 5/6/7/8 红形成顺序通过参考项目原计算器逐步重放。17 个角色的两种传承技选项所生成的 34 份配置与参考实现逐字节比对，覆盖属性、技能、天赋和潜能记录。尚未进行游戏内实测，使用前请保留原始备份。
